# Снимки данных для тестов

Реальные выгрузки ETL на 05.09.2026: тесты собирают на них страницы и проверяют
блоки. Раньше они лежали в игнорируемой `out/`, поэтому набор жил только на одной
машине и свежий клон репозитория тесты прогнать не мог.

Обновлять, когда меняется формат выгрузки, а не при каждом изменении цифр:
```
python3 radar.py out/radar.json out/pulse.json out/trade.json && cp out/radar.json fixtures/
```
